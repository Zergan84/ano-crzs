# Официальный портал АНО «ЦРЗС»

**Полное наименование:**  
Автономная некоммерческая организация «Центр развития зимнего спорта, современных спортивных технологий и туризма»

**Сокращенное наименование:**  
АНО «ЦРЗС»

---

## 🏛 Концепция и архитектура

Официальный профессиональный отраслевой веб-портал, выполненный в строгой государственной/институциональной стилистике (подобно порталам общероссийских спортивных федераций и отраслевых ведомств РФ, с референсом архитектуры ФГССР).

* **Строгая цветовая гамма:** Официальный темно-синий (`#0A2540`), сланцевый графит (`#1E293B`), глубокий акцентный синий (`#1D4ED8`), сдержанный акцентный красный (`#C53030`), нейтральный серый фон (`#F8FAFC`).
* **Без коммерческого стиля:** Отсутствуют рекламные баннеры, неоновые градиенты, 3D-анимации и стиль магазинов экипировки. Выдержан деловой строгий стиль некоммерческой организации.
* **Независимая архитектура данных:** Все сущности (реестр специалистов, новости, события, документы, учебные программы, структура) вынесены в типизированные модули в `src/data/`, что позволяет бесшовно подключить Postgres / Supabase / Strapi / Headless CMS.

---

## 📑 Разделы и страницы портала

1. **Главная страница (`/`)**
   - Официальный институциональный баннер с гербом/эмблемой организации и правовым статусом.
   - Экспресс-поиск по Единому Реестру специалистов.
   - Статистические показатели (1480+ специалистов, 54 региона, 42 стандарта).
   - 6 ключевых уставных направлений деятельности.
   - Превью Реестра специалистов со статусами и верификацией.
   - Сводка новостей пресс-службы и календарь ближайших мероприятий.
   - Нормативная база и блок отраслевых партнеров.
2. **Об организации (`/about`)**
   - Уставные цели, предмет деятельности, научные и правовые принципы.
   - Юридические реквизиты (ОГРН, ИНН, КПП, ОКПО).
3. **Органы управления и структура (`/about/structure`)**
   - Правление организации и Генеральный директор.
   - Экспертный совет по технической безопасности и технологиям.
   - Методическая и ревизионная комиссии.
4. **Направления деятельности (`/activities`)**
   - Стандартизация и регламенты зимнего спорта.
   - Подготовка и аттестация тренерско-инструкторских кадров.
   - Спортивные технологии, аналитика и цифра.
   - Безопасность на трассах и противолавинный мониторинг.
   - Развитие всесезонного спортивно-оздоровительного туризма.
   - Научно-методическая и экспертная деятельность.
5. **Единый реестр специалистов (`/specialists`)**
   - Живой поиск по ФИО, номеру свидетельства (`RU-ЦРЗС-...`), региону, месту работы.
   - Фильтры по дисциплине (горные лыжи, сноуборд, фристайл, беговые лыжи, ски-альпинизм, инструкторская деятельность).
   - Фильтры по квалификации (Категории А, В, С, судьи).
   - Фильтры по статусу свидетельства (Действителен, На продлении, Архив).
   - Модальное окно **электронного свидетельства с печатью ЭЦП** и кнопкой печати официальной выписки.
6. **Обучение и аттестация (`/education`)**
   - Ступенчатая система категорий (С, В, А).
   - Карточки образовательных программ с часами, темами и выдаваемыми свидетельствами.
   - Регламент подтверждения квалификации (переаттестация).
7. **Календарь мероприятий (`/events`)**
   - Фильтрация по типам (семинары, курсы, конференции, судейские сборы) и статусам.
   - Отображение локаций, квот участников и оставшихся мест.
8. **Электронный депозитарий документов (`/documents`)**
   - Категории: Учредительные, Регламенты и стандарты, Методические материалы, Отчетность Минюста РФ.
   - Номера документов, даты утверждения, размер файлов, триггер скачивания PDF.
9. **Пресс-центр (`/news`)**
   - Официальные сообщения и релизы с номерами (ПР-ЦРЗС/...).
   - Фильтрация по рубрикам.
   - Чтение полного текста релиза в модальном окне.
10. **Членство и подача заявлений (`/membership`)**
    - Форма подачи для физических лиц (инструкторов) и юридических лиц (курортов).
    - Выбор программ и квалификаций.
    - Согласие на обработку данных по 152-ФЗ.
    - Генерация официального трекинг-номера учетного дела (напр., `ЗВ-2025-4198`).
11. **Фотохроника (`/gallery`)**
    - Фотоальбомы со сборов, полевых испытаний датчиков, аудита трасс и конференций.
12. **Контакты и реквизиты (`/contacts`)**
    - Карточки подразделений, многоканальный телефон, email.
    - Банковские реквизиты с кнопкой быстрого копирования.
    - Электронная приемная для направления обращений.
    - Схема проезда (п. Архангельское, Красногорск).

## 🚀 Запуск и сборка

```bash
# Установка зависимостей (уже выполнены в проекте)
npm install

# Запуск в режиме разработки
npm run dev

# Проверка типов и производственная сборка
npm run build

# Запуск производственного сервера
npm start
```
